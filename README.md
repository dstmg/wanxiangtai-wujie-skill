# 万相台无界投放顾问 Skill

电商腿毛哥整理的万相台操作问答 Skill，面向淘宝和天猫运营。公开版提供五个专题指南，资料核对日期为 2026 年 11 月 14 日。功能、权限和活动规则以商家后台和对应期官方说明为准。

## 使用

下载仓库，把包含 SKILL.md 和 references 目录的文件夹命名为 wanxiangtai-wujie，再按宿主的 Skill 导入方式安装。也可以直接打开 SKILL.md，按问题阅读对应专题。

## 接入旧版完整资料

如果你已有原版资料包，把旧包的 `INDEX.md` 和整个 `refs/` 复制到新版 `SKILL.md` 同一目录。原版共 597 篇参考正文，覆盖关键词推广、人群推广、货品全站推广、店铺直达、内容营销、线索推广、报表和账户等。连接后，同一个 Skill 可以查五个更新专题，也可以沿用旧索引查原来的参考正文。发布目录和本地装有语料的副本请分开保存。

```text
wanxiangtai-wujie/
├── SKILL.md
├── references/
├── INDEX.md     本地原版资料包提供
└── refs/        本地原版资料包提供
```

也可以在提问时提供原版资料包的本地绝对路径。请使用你有权访问的资料。GitHub 下载包提供五个操作专题和官方入口。未接入旧包时，其他问题仍可查线上官方手册，按账号权限访问。
