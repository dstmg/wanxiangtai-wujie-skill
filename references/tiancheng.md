# 万相天成 β

核对日期为 2026-11-14。官方资料位于「新万相无界对客知识文档 → 四、万相天成 β」，主要依据是《万相天成 β 使用白皮书》和《【内测中】万相天成 β 支持钉钉微信直连》。[官方知识文档](https://alidocs.dingtalk.com/i/nodes/Obva6QBXJwxNZoMOCgk2g90E8n4qY5Pr)

## 进入与排查

1. 登录目标店铺的万相台无界版，在顶部导航栏找「万相天成 β」，或用[白皮书提供的直达入口](https://one.alimama.com/index.html#!/home/index?aioperation=showAiPopup)。
2. 入口缺失时，先核对当前店铺和直达页提示。已读白皮书未给出产品级通用申请入口或全量资格。请用户提供后台提示，按该店铺实际状态判断。
3. 只有「消息渠道」缺失时，优先核对账号角色。白皮书记录过主账号绑定限制，子账号支持的时间属于预估，当前账号是否可绑以页面为准。微信在白皮书中是少量开放，钉钉 Bot 逐步灰度，两者均未提供白名单申请。

## 任务怎么选

| 目标 | 操作 |
|---|---|
| 生成一套投放方案 | 进入「创建投放方案」，输入商品、经营目标和预算要求。竞争学习模式可自选至少 5 个对标商品，建议对齐价格带和运营阶段。Agent 大师模式根据经营目标、商品阶段和投放偏好生成方案。检查场景、预算和目标后再决定是否投放。 |
| 定时看数据 | 配置任务名称、执行频率、执行时间和自然语言动作。首次可配置为查看昨日投放表现并输出摘要。到执行详情检查运行时间、报告和成功或失败状态。需要主动通知时先绑定消息渠道。 |
| 诊断现有计划 | 计划护航适用于计划诊断和托管。希望先理解问题时先看分析。有明确授权需求时可使用「新建护航任务」，在确认前核对护航计划和授权范围。官方白皮书提示 AI 预警出现红黄灯时需人工干预，包含核对预算和处理后台预警。 |
| 复用自己的判断条件 | 「技能库」含官方技能与「我的技能」。白皮书建议把触发判断条件及预期调优动作写清楚。上传格式、执行效果和授权范围需在平台实测。 |

## 手机消息

- 进入「万相天成 β → 消息渠道」，按页面支持的渠道完成绑定。[官方消息渠道入口](https://one.alimama.com/index.html#!/home/index?agent_menu=channel)
- 接收不到定时任务消息时，检查任务执行日志、绑定状态和渠道权限。白皮书记载微信 ClawBot 在近期有互动时才可主动发消息，并建议每天与其互动。钉钉绑定后可在钉钉搜索「万相天成 β」查找会话。
- 仅按用户授权做问答和操作指导。对话生成方案、配置任务和授予投放调整权限分别确认，避免把生成的建议描述成已执行投放。

## 领航宝贝任务

[领航宝贝任务官方说明](https://alidocs.dingtalk.com/i/nodes/gwva2dxOW4vRkd9DU0OrlDv9Jbkz3BRL)记载该能力当前为少量内测。页面没有入口时先看店铺是否开放领航，再分别判断是否能使用普通天成入口、计划护航或消息渠道。

- **领航按商品托管，护航按单计划托管。** 被领航托管的计划如果原来在护航，将由领航接管。启动前确认关联计划、托管周期、目标与每日预算上限。
- 选择目标商品和玩法后，核对关联存量计划和额外预算，检查生成方案及授权，再由商家决定是否「立即启动领航」。托管预算上限不能低于已关联计划的日预算总和。
- 允许新建全站推计划时，如果商品所有计划均交给领航，系统可能关闭互斥计划。如果只有部分计划关联且存在全站互斥，说明写明系统不会为其新建全站推。上线前按店铺现有计划确认影响。
- 「领航任务管理 → 详情」可查看关联计划组数据和任务进度。报表展示关联计划的聚合表现，评估额外增量需要另立对照。
